AlterOffice – CRM interne alternants

SaaS & Développement Web

AlterOffice est une application web interne développée dans le cadre de la formation BTS SIO. Face au constat que les alternants n'avaient pas accès au logiciel métier Assure Office, un outil SaaS simplifié a été conçu pour leur permettre de saisir et de gérer les informations clients directement depuis un navigateur. L'application permet notamment de renseigner les données d'un contact (nom, prénom, téléphone, email, adresse, profession, date de visite, assurance souhaitée) et de les soumettre automatiquement vers un Google Sheet via une API Google Apps Script.

  • Analyse du besoin et conception de l'architecture de l'application.
  • Développement du formulaire de saisie client (HTML, CSS, JavaScript).
  • Intégration de l'API Google Apps Script pour la soumission des données vers Google Sheets.
  • Mise en place d'une interface épurée et responsive, utilisable sans installation.
  • Tests fonctionnels et corrections d'anomalies.

Application d'administration GitLab

API REST & Automatisation

Dans le cadre de la formation BTS SIO option SLAM, ce projet visait à développer une application web permettant d'automatiser les tâches administratives répétitives sur une instance GitLab. Le besoin est né d'un constat : certaines opérations de fin d'année scolaire — gestion des projets, des utilisateurs et des groupes — s'avèrent longues et fastidieuses lorsqu'elles sont effectuées manuellement. L'application exploite l'API REST de GitLab pour permettre des actions groupées efficaces.

L'application permet aux administrateurs GitLab de :

  • Gérer les projets, utilisateurs et groupes depuis une interface unifiée.
  • Effectuer des actions groupées sur plusieurs ressources simultanément.
  • Créer des issues identiques sur plusieurs projets en un seul clic.
  • Supprimer un ou plusieurs projets avec message de confirmation intégré.
  • Modifier la visibilité de plusieurs projets en lot.
  • Afficher des alertes contextuelles en cas d'absence de sélection.

AP41 — Application React Native & API REST

Mobile & React Native

Dans la continuité du projet AP32, ce projet consiste à développer une application mobile permettant d'afficher les stages, les étudiants, les organisations et les contacts. L'application est connectée à l'API REST conçue lors du projet AP32, ce qui permet de récupérer et d'afficher dynamiquement les données depuis un backend Symfony. Ce projet met en pratique le développement cross-platform avec React Native ainsi que l'intégration d'une API REST dans un contexte mobile.

React Native API REST JavaScript GitLab
  • Affichage des stages, étudiants, organisations et contacts depuis l'API AP32.
  • Consommation de l'API REST Symfony en HTTP depuis l'application mobile.
  • Navigation entre les écrans (liste, détail) avec React Navigation.
  • Application compatible Android et iOS grâce à React Native.
